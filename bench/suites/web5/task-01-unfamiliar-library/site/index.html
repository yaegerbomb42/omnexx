tallyhq 3 API reference

tallyhq keeps exact decimal totals: no floating point anywhere.

Breaking changes in v3

  • The top-level add(a, b) helper was removed. Use a tally.
  • Amounts must be decimal strings such as "19.99". Numbers throw a TypeError.
  • total() now returns an object, not a string.

createTally(options)

Creates a running tally. Options:

Option Default Meaning
places 2 Decimal places of the total.
mode "up" Rounding: "up" (half away from zero), "even" (half to even, banker's rounding), or "down" (truncate).

Rounding applies once, to the total, never to each amount.

tally.add(amount)

Adds a decimal string. Returns the tally, so calls chain.

tally.total()

Returns { value, count }: value is the rounded total as a string with exactly places decimals, count how many amounts were added. 

import { createTally } from 'tallyhq';
const t = createTally({ mode: 'even' });
t.add('0.125').add('1.000');
t.total(); // { value: '1.12', count: 2 }
