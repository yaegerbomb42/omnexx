Migrating to datekit v2

v2 replaces the free functions with an immutable DateKit class.

Parsing

parse(str, pattern) is gone. Use DateKit.from(str, { pattern }). It throws a RangeError when the string doesn't match or the date doesn't exist (e.g. 31/02).

Pattern tokens

Tokens follow Unicode: YYYY is now yyyy and DD is now dd. MM is unchanged. Old tokens throw.

Formatting

format(date, pattern) is now the method kit.format(pattern).

Arithmetic

addDays(date, n) is now kit.plus({ days: n }), which returns a new DateKit. 

// v1
format(addDays(parse('05/03/2026', 'DD/MM/YYYY'), 1), 'YYYY-MM-DD');
// v2
DateKit.from('05/03/2026', { pattern: 'dd/MM/yyyy' }).plus({ days: 1 }).format('yyyy-MM-dd');
