## Features only omnexx has (verified)

"Verified" here means we found no competitor documenting the feature. It does not prove no competitor has it, and many competitor cells are "?".

- **Ratchet gating plus anti-cheat (test tampering or hardcoding).** No competitor documents this. The closest are Claude Code hooks and Cline `--hook-command`, which are generic policy hooks, and Factory's validator, which does not document ratchet or anti-cheat.
- **A final audit against an explicit "done when".** The only near equivalent is Factory Missions' validator role.
- **A per-model quota ledger shared across sessions.** OpenClaw's cooldowns are per auth profile, and its open issues (#10375, #23815) describe exactly the gap omnexx fills: one model's quota blocks a whole profile, and cooldowns spill across providers and sessions. Oh My Pi tracks backoff per credential, not per model.
- **A user-selectable model pool with random rotation.** OpenClaw and Hermes only have ordered fallback lists.
- **Built-in $ budget caps.** We could not verify these for any competitor. This is "unverified elsewhere", not "proven absent".

## Where competitors lead us

- **Provider breadth.** OpenCode supports 75+ providers via models.dev and Oh My Pi 60+, against our ~30.
- **Proven multi-day orchestration.** Factory Missions has public multi-day claims, per-role model pinning (orchestrator, worker, validator) and git-coordinated handoffs.
- **Surfaces and ecosystem.**
  - Hermes has a desktop app, messaging gateways, cron jobs, remote and sandbox backends (Docker, SSH, Modal), self-improving skills and pluggable memory providers.
  - Copilot CLI has GitHub integration and a fully offline mode.
  - Poolside is an ACP server and client and works in Zed and JetBrains.
- **IDE depth.** Oh My Pi has LSP and DAP integration (14 LSP and 28 DAP operations) and hashline edits.
- **Multi-model competition.** Qwen Code's Agent Arena (experimental) runs up to 5 models on one task in separate worktrees.
- **Learned routing.** No competitor showed verified learned routing either, so our "in progress" is not behind. But nobody leads here yet, so shipping it would be a differentiator.
