# M0: Skeleton

## Scope

Repo, toolchain, CLI skeleton, config schema and loader, `omnexx init`, `omnexx doctor`, CI (plan §8 M0, handoff §4.1).

## Design

| Module                                           | Responsibility                                                                                                                                                                                                                                                                                                                                                                |
| ------------------------------------------------ | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `src/errors.ts`                                  | `OmnexxError` base class with a stable `code` and an actionable `hint`. Subclasses: `ConfigError`, `NotImplementedError`, and later `PolicyError`, `GitError`, `ProviderError`, `LockError`, `StateError`. The CLI prints `error[code]: message (hint)` on one line.                                                                                                          |
| `src/config/schema.ts`                           | One zod schema for the whole config surface, including `[budget]` (24 h defaults and `wrapup_reserve`, plan §14.5), `[judge]`, `[judge.nimble]` and `[workers]` (plan §15.3: `max_concurrent = 1`, `priority`, and one table per worker id, all `enabled = false`) so later milestones don't change it. Durations are strings like `"5m"` parsed by `src/config/duration.ts`. |
| `src/config/defaults.ts`                         | Default values (the schema's `.default()`s) and the default protected-path list.                                                                                                                                                                                                                                                                                              |
| `src/config/load.ts`                             | Precedence: CLI flags > `OMNEXX_*` env > `./omnexx.toml` > `~/.config/omnexx/config.toml` > defaults. Deep merge of plain objects; arrays replace. A zod failure becomes one line: `config error in <source>: <path>: <message>`.                                                                                                                                             |
| `src/core/paths.ts`                              | `OMNEXX_HOME` (default `~/.omnexx`) and `OMNEXX_CONFIG_HOME` (default `~/.config/omnexx`), so tests never touch the real home.                                                                                                                                                                                                                                                |
| `src/cli/index.ts`                               | commander program, `--version` from package.json, exit-code mapping, error printing.                                                                                                                                                                                                                                                                                          |
| `src/cli/commands/init.ts` + `src/cli/detect.ts` | Detects package manager (lockfiles) and gates (package.json scripts, vitest/jest/tsc/eslint, pytest, go). Renders `omnexx.toml`, asks before writing (injected stdin), `--yes` skips the prompt, never overwrites an existing file (idempotent).                                                                                                                              |
| `src/cli/commands/doctor.ts`                     | Checks Node ≥ 22, git, rg, key (masked), docker when `sandbox = "docker"`, provider network (skipped by `--offline`), and judge endpoint when `[judge] kind = "nimble"` (version ≥ 0.35, `nimble` model pulled, latency, non-loopback/non-Tailscale warning). Returns structured results so tests can assert on them.                                                         |
| `src/auth/keys.ts`                               | Key lookup order: `OMNEXX_ANTHROPIC_API_KEY`, `ANTHROPIC_API_KEY`, then `~/.config/omnexx/credentials/anthropic.key` (0600). `maskKey()` keeps the prefix and last 4 characters.                                                                                                                                                                                              |
