# M1: Single-session agent loop

## Scope

Plan §8 M1 plus handoff §4.2: Anthropic provider (stable cached prefix, breakpoints, retries, usage and cost), tools (`read`, `outline`, `search`, `str_replace`/`multi_edit`/`write_file`, `bash`, `read_log`, `remember`), path jail, command policy, env scrubbing, redaction, git worktree on `omnexx/<runId>`, one full cycle (act → gates → ratchet + anti-cheat → commit with trailers, or rollback to `lastGreen`), JSONL event log, `run --plan-only`. Pulled forward: per-cycle caps, pre-flight cost check, run-level `max_usd`. Judge interface with `none`/`nimble`/`llm`, fail-open breaker, tool-call safety (log-only).

## Design

| Area      | Files                                                                | Notes                                                                                                                                                                                                                                                                                                                                                                                                                                                        |
| --------- | -------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| Security  | `src/security/{redact,paths,command-policy,env-scrub,glob}.ts`       | Redactor masks known secret env values plus token patterns. Jail resolves realpath of the deepest existing ancestor, compares case-insensitively on macOS, denies secret-looking paths. Policy parses with shell-quote and splits on control operators; denies sudo, remote git, `git` writes, network tools, kill, publish, crontab, docker, writes outside the worktree, secret paths, secret env references, command substitution; recurses into `sh -c`. |
| Git       | `src/git/{git,worktree,checkpoint,rollback,trailers}.ts`             | Worktree under `$OMNEXX_HOME/worktrees`. Commits use `--no-verify`, `commit.gpgsign=false`, trailers `Omnexx-Run/Task/Cycle`. Rollback saves `rejected/<cycle>.patch`, then `reset --hard` + `clean -fd` inside the worktree only.                                                                                                                                                                                                                           |
| Verify    | `src/verify/{gates,ratchet,anticheat,parsers/*}.ts`                  | Gates run harness-side with timeout and process-tree kill, full log under `logs/`. Parsers: vitest, jest, node-test (TAP), tsc, eslint, pytest, gotest, generic. Ratchet: must-pass = exit 0; ratchet = no new failure IDs and count not higher than baseline. Anti-cheat on the diff vs `lastGreen`.                                                                                                                                                        |
| Providers | `src/providers/{types,pricing,anthropic,retry}.ts`                   | Provider-neutral message types. Breakpoints: last system block, the cycle-state block, the latest message. Retry with exponential backoff to 30 min on 429/5xx/529/network, injected clock.                                                                                                                                                                                                                                                                  |
| Agent     | `src/agent/{context,loop,prompts,repo-map}.ts`                       | Fresh context per cycle. Notes are snapshotted at cycle start so the prefix is byte-identical within a cycle.                                                                                                                                                                                                                                                                                                                                                |
| Guard     | `src/guard/budget.ts`                                                | Pre-flight: estimated input × max(input, cache-write) price + `max_tokens` × output price.                                                                                                                                                                                                                                                                                                                                                                   |
| Judge     | `src/judge/{types,none,nimble,llm,breaker,factory,state-summary}.ts` | Fail-open, half-open breaker, size limits.                                                                                                                                                                                                                                                                                                                                                                                                                   |
| Core      | `src/core/{events,atomic,run-store,cycle,plan,clock}.ts`             | Plan is the hierarchical tree from day one (goal → milestones → tasks).                                                                                                                                                                                                                                                                                                                                                                                      |

## Proof of acceptance

Integration tests in `test/integration/` drive the scripted provider (`test/support/scripted-provider.ts`) against fixture repos in `test/fixtures/repos/` that use `node --test`, so no `npm install` is needed: `ts-failing-test` (one commit, trailers), `impossible-task` (rejected, tree identical), `ratchet` (pre-existing failure stays, cycle accepted), `test-deleter`, `.skip/.only` insertion and protected path (rejected), safety attempts (refused, logged, zero secret hits), original checkout untouched. Property tests: fresh context bound across cycle 1 vs 500, budget overshoot ≤ one turn. Judge off = zero HTTP calls. The real-API e2e lives in `test/e2e/` behind `OMNEXX_E2E=1` and is not run.
